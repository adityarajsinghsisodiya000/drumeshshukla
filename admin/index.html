How this console works

  • Login is verified on the server (signed HttpOnly cookie, 8 hour session).
  • Enquiries are encrypted (AES-256-GCM) before they are stored in the data branch, so the public repository only holds ciphertext.
  • Each form submission also opens WhatsApp, so the visitor can confirm instantly.
  • The site itself stays fully static — no database to maintain, no monthly cost.
